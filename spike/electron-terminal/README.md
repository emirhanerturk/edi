# Atılacak deneme: Electron içinde terminal

Tek soruyu yanıtlamak için yazıldı: **bu terminalin içinde Claude Code ile yaşanabilir mi?**
Ürün kodu değil; testleri yok, karar verildikten sonra silinecek.

```sh
cd spike/electron-terminal
npm start -- ~/studios/quizei
```

Denenecekler:

- Türkçe klavyede Option'lı karakterler (`@ # { } [ ] | \ ~`), `ı ğ ü ş ö ç İ`
- Claude Code içinde Shift+Enter (yeni satır), Esc, ok tuşları, yapıştırma (uzun metin dahil)
- Seçip Cmd+C, Cmd+V; fareyle kaydırma; pencereyi yeniden boyutlandırma
- Uzun çıktıda hız (`git log`, `cat` büyük dosya), renkler, yazı tipi
- Cmd+T yeni terminal, Cmd+1..9 sekme, Cmd+W sekmeyi kapat

Sağdaki repo listesi salt okunur; hiçbir git yazma işlemi yapmaz.
